# Polar Client — Fabric mod

Minecraft 26.3 · Fabric Loader 0.20.1+ · Fabric API 0.165.0+26.3 · Java 25

```bash
./gradlew build       # build/libs/polarclient-1.0.0.jar
./gradlew runClient   # test in a dev client
```

Layout (`src/main/java/dev/polarclient`):

- `PolarClient` — entrypoint: config, key binds, HUD, events
- `module/` — `Module`, `HudModule` (draggable, edge-anchored), `TextHudModule`, `ModuleManager`
- `modules/` + `modules/hud/` — the 26 features
- `setting/` — boolean, number (slider), mode, color (+chroma, alpha), text settings
- `gui/` — `PolarMenuScreen` (Right Shift), `HudEditorScreen`, `PolarTitleScreen` (main menu), `MenuBackground` (animated background), `BackgroundData` (generated by `tools/menu-background/post.py`)
- `hud/HudRenderer` — draws HUD mods via `HudElementRegistry` and wraps vanilla layers (crosshair, scoreboard, ...)
- `mixin/` — zoom + freelook (`Camera`), freelook mouse (`Entity.turn`), scroll zoom (`MouseHandler`), fullbright (`LightmapRenderStateExtractor`), window title (`Minecraft`), main menu (`Gui.setScreen`)

To add a mod: extend `Module` (or `TextHudModule` for a text HUD element), add settings with `add(...)`, and register it in `ModuleManager`. It shows up in the menu and is saved automatically.

See the main README one folder up for everything else.
